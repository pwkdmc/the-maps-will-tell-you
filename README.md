# Oblique Strategies Landing Page
A responsive landing page dedicated to Oblique Strategies — a creative tool created by Brian Eno and Peter Schmidt to overcome creative blocks. This project showcases information about the deck, its history, and how it works, with a theme switcher (dark/light mode).
## Features
- Dark/Light theme toggle — persists user preference via localStorage.
- Responsive design — adapts to different screen sizes.
- Modern image formats — serves AVIF and WebP for optimized performance.
- Semantic HTML — accessible and well-structured content.
- Interactive UI elements — hover and focus states for buttons and links.
## Technologies
- HTML5
- CSS3 (custom properties, responsive units, flexbox)
- JavaScript (theme switcher, localStorage)
- SVG icons
- Responsive images (<picture> with srcset)
## Responsive Design
- Uses clamp() for fluid typography.
- Viewport-relative units (vi, vw, %) for layout.
- Flexible images and cards adapt to container size.
## Browser Support
- Modern browsers (Chrome, Firefox, Safari, Edge)
- Supports AVIF, WebP, and PNG fallbacks
- JavaScript required for theme switcher
